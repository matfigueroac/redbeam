# Política de privacidad de RedBeam

RedBeam procesa los planos y sus anotaciones en el equipo. La aplicación guarda las preferencias y la lista de archivos recientes de forma local. Puedes abrir un plano de ejemplo y utilizar las herramientas sin crear una cuenta. RedBeam no incorpora telemetría ni envía tus planos a un servidor.

La versión de GitHub consulta GitHub Releases para buscar actualizaciones y descarga el instalador cuando lo solicitas. La edición de Microsoft Store recibe las actualizaciones a través de la tienda. Los enlaces externos que elijas abrir se gestionan con tu navegador.

Si tienes preguntas sobre el uso de tus datos, puedes contactar al mantenedor desde el [repositorio de RedBeam](https://github.com/matfigueroac/redbeam).
